| Status | Iteration                  | Persona               |

## Implementation notes

- Parsing: `src/domain/track/gpx.ts`, statistics: `track.ts` / `geo.ts`, profile drawing: `profile.ts`.
- GPX waypoints (`<wpt>`) are parsed and kept as checkpoint candidates for [US2](us02-mark-checkpoints.md).
- The loaded track is held in memory only – persisting plans is part of [US5](us05-multiple-route-plans.md).
- Browser tests use the synthetic fixture `e2e/fixtures/sample-loop.gpx` (regenerate with
  `node tooling/generate-sample-gpx.ts`) and stub the map tiles.
